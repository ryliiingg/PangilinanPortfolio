How to run the website and use its admin page.

Run it on the computer

1. Put folder in C:\xampp\htdocs\ (it should be C:\xampp\htdocs\Portfolio_Pangilinan).
2. Open the XAMPP Control Panel and click Start next to Apache.
3. Open http://localhost/Portfolio_Pangilinan/ in browser.
